# 资产生产 SOP:锚定—派生(防资产漂移)

> 这套打法在**代码**域防漂移靠「决策宪法 + 派工 + 机器 gate」。
> 本文是它在**视觉资产**域的同构实例:**先出一张概念锚图(宪法),再从锚派生所有角色/资产,机器+人守一致性门 —— 资产就不跑偏。**
> 思想工具无关;文末给一份**参考实现**(`image-work-flow` CLI)。你换任何生图后端,套路不变。

---

## 为什么:风格会「漂」

跨多张资产**只靠文字 style prompt** 描述风格,一致性大概只能到 65–75% —— 第 3 张角色的描边、配色、视角就开始和第 1 张对不上了。文字是低带宽的风格载体,每张都在「重新发挥」。

防漂移的通用解法在 kit 里已经有了:**别让每次产出重新发挥,锚一个权威源,所有产出从它派生,并在每次产出时重申不变量。** 代码域那个锚是 `decisions.md`;资产域那个锚是**一张概念图**。把概念图当视觉参考喂给每一次生成 + 每次重申硬约束,一致性能拉到 90%+。

---

## 心智模型:两阶段(探索 → 生产)

这是真用起来最关键的认知。**别跳过探索直接生产**,否则「风格出来了,但不是你想要的」。

```
[Phase 1 · 探索]                         [Phase 2 · 生产]
N 个独立方向,各出 1 张概念图             选定 1 个方向 → 1 张锚图 + N 个资产
不同美学坐标(像素/布偶/扁平/手绘…)     每个资产锚定概念图 + 重申不变量
便宜、并行、用完即弃                      锚图一旦定,只在框内出活
目的:选定一个视觉方向                    目的:在选定方向内出整套不跑偏的资产
```

- Phase 1 的每个方向 prompt 要**真不一样**(不同美学坐标,不是同调色板微调)。并行出图,打开挑一个。
- 这一步对应方法论的 **DD-first / 先拍方向再派实现**:方向是廉价可逆的探索期决策,定了就锁,进入生产期不再摇摆。

---

## 锚定—派生:核心机制

选定方向后:

1. **概念图 = 视觉宪法。** 这张图(`concept.png`)是这套资产的唯一权威风格源,等价于 `decisions.md` 里那条「视觉方向锁定」DEC。
2. **每个资产都锚定它派生。** 生成每张角色/场景时,把概念图作为视觉参考一起传(如生图 API 的 `image=[concept.png]`/edits 端点),而不是只靠文字。
3. **每次重申不变量(restate invariants on every iteration)。** 每次生成都把风格 DNA 全文重传一遍(描边宽度、配色 hex、阴影方向、角色比例、视角)。这正是 append-only 记忆的视觉版:**不让模型「忘记」宪法**。token 成本相对图本身可忽略,降漂效果最大。

> 派生 ≠ 复制。角色图各不相同,但都从同一张锚图继承风格 DNA —— 就像不同 agent 写不同模块,但都守同一份 HARNESS。

---

## 风格 DNA + 人工 checkpoint(机器抽取,人补漏)

锚图定了之后,抽出一份**文字版风格 DNA**(`anchor.md`)给后续每次生成重申。可以用 vision 模型自动反推,但**必须人工过一遍**——这是机器 gate 的人肉补门(对应 §4 视觉 detection-gate)。

风格 DNA 至少覆盖:**光照 / 配色(主色辅色禁色 hex)/ 媒介(像素·手绘·3D,描边·AA·渐变)/ 构图(视角·透视·基线)/ 情绪**,外加一组 **Invariants(DO NOT DRIFT)** 硬约束。

> **人工 checkpoint 真影响最终质量,别跳。** 典型坑:vision 模型常把 3/4 等距视角误判成 "Top-down orthographic",这个错误会**传染给所有后续资产**。人手改对、补上机器看不出的硬约束(「描边恰好 2px」「阴影永远 bottom-right」「chibi 头身比 1/3」),再开始批量生产。

---

## 一致性 gate:机器守能守的,人签人眼的

和代码任务一样,资产交付前过门(对应方法论 §4):

- **机器门**(能自动的):
  - **schema 校验** —— 资产清单(manifest)结构、命名唯一性、尺寸规格(如 16 倍数 / 长边上限)在出图前先过,别等花了钱才报 typo。
  - **后处理硬指标** —— 如透明背景走「纯色背景 + chroma-key」时,校验抠图残留像素数低于阈值;尺寸/格式/数量对账。
  - **可复现锁** —— 每张产出旁存 prompt 的 hash;锁文件(`*.lock.json`)记全部 prompt hash + image hash + 时间戳,**进 git**,PR diff 能看到资产 prompt 变更。
- **人肉门**(只能人眼的):产出后**同框比对**既有资产,风格 sanity 不达标重做。视觉一致性最终要 Director / art 亲眼签字 —— 这是 §4「真机才抓得到的坑机器补不全」在资产域的体现。

**幂等 = 省钱也是 gate**:prompt 没改且产物在 → skip 不重复生成;prompt 改了 → 视为新版本重出。反复迭代措辞而不重复扣费,等价于代码域的「改了才重测」。

## 映射回方法论(为什么这属于这套 kit)

| 资产 SOP | = 方法论的哪条 |
|---|---|
| 概念锚图 = 视觉宪法 | §3 `decisions.md` 决策宪法 |
| 每张资产重申不变量 | §3 append-only 记忆,不让模型忘 |
| 两阶段:探索 N → 锁 1 → 生产 | §8 DD-first;探索期决策可逆、生产期锁定 scope |
| `anchor.md` 机器抽取 + 人工 checkpoint | §4 视觉 detection-gate:机器守能守的,人签人眼的 |
| manifest schema 校验 / chroma 残留 / lock hash | §4 机器 gate + 记账 / 可复现 |
| 风格不达标 handback raise DEC | §8.11 方向变更 codify DEC |

**一句话:资产防漂移 = 防漂移三件套 + 机器 gate 在视觉域的一次套用。** 不是新方法论,是同一套思想换了介质。

---

## art 角色怎么落地

`art` agent 接 Director 派工后,按本 SOP 执行:

1. **方向未锁** → 先做 Phase 1 探索(N 个方向各 1 张概念图),handback 给 Director / 用户挑 → 挑定的方向 raise 一条「视觉方向锁定」DEC candidate(§8.11,art 不自己拍板)。
2. **方向已锁** → 概念图作锚,抽 + 人工校 `anchor.md`,锚定派生每个资产。
3. 出图后过**一致性 gate**(schema / 后处理指标 / 同框比对),不达标重做。
4. 交付资产文件 + 风格 DNA + lock + 自检结论;**资产的代码接入归 `ux`/`engine`**(art-only 交付边界不变)。

## 参考实现:`image-work-flow`

把上面的思想 CLI 化的一个现成工具(独立仓,非本 kit 一部分):一份 `manifest.yaml` 描述概念 + 资产清单,5 阶段编排 `validate → concept → anchor → assets → lock`,概念图作 `/edits` 锚、每次重申 `anchor.md`、chroma-key 抠透明、prompt hash 幂等、lock 进 git。完整新游戏的资产探索+生产实测 < $1。

它只是**思想的一种落地**。你换 Midjourney / SD / 别的生图后端,只要保住「**两阶段 + 锚定派生 + 重申不变量 + 一致性 gate**」这四点,效果一样 —— 因为防漂移的是流程,不是某个 API。
